# SQL Learning Repository 🗄️

A beginner-friendly collection of SQL notes, examples, and practice queries. The examples use broadly supported SQL syntax and are suitable for learning relational database concepts.

## Topics covered
1. Database and table basics
2. Creating and modifying tables
3. Inserting, updating, and deleting records
4. Filtering and sorting data
5. Aggregate functions and grouping
6. INNER, LEFT, and other joins
7. Subqueries
8. Constraints and data integrity

## How to use
1. Install or open a SQL database tool such as MySQL Workbench, PostgreSQL with pgAdmin, or SQLite.
2. Open a `.sql` file and run the statements in order.
3. Start with `sample_data.sql` to create the example database and tables.
4. Run the topic files to practice the queries.

> Note: Some syntax differs between database systems. The core examples are standard SQL, but date functions and auto-increment syntax may vary by database.

## Learning goals
- Understand relational databases and tables.
- Practice CRUD operations.
- Retrieve and filter records.
- Summarize data with aggregate functions.
- Combine related data using joins.
- Write subqueries and use constraints.

## Practice challenge
After running `sample_data.sql`, try to:
- Display all students in alphabetical order.
- Find students with marks above 80.
- Calculate the average mark by department.
- Show each student with their department name.
- Find students whose marks are higher than the overall average.
